# Original Hourlark bird logo assets

Extracted locally from the approved first imagegen concept with user authorization.
The original bird silhouette and wordmark are retained; the white matte was removed.
The source has subtle color variation, which is retained in the exported amber bird.
These are raster assets, not vector files.

- `logo-light.png`: transparent stacked logo with original charcoal wordmark.
- `logo-dark.png`: transparent stacked logo with white wordmark.
- `bird-amber.png`: transparent standalone original bird on a square canvas.
- `wordmark-light.png` and `wordmark-dark.png`: original wordmark for light and dark backgrounds.
- `icon-{16,32,48,180,192,512}.png`: square transparent bird icons.
- `favicon.ico`: 16, 32, 48, 64, 128 and 256 pixel favicon frames.
- `original-concept.png`: untouched original concept, including its white background.
- `preview.png`: assets shown on light and dark backgrounds.

The 180 pixel icon can be used for an Apple touch icon; the 192 and 512 pixel
icons are available for app manifests. The navigation uses the bird and white
wordmark. Login, loading and workspace error screens use the full dark-background logo.
The document head uses the ICO, 16/32 pixel PNG favicons and 180 pixel touch icon.
